# Установка и запуск парсера

## Быстрый старт (для любого Windows ПК)

### 1. Требования
- Python 3.7+ (загрузить с https://www.python.org/)
- Chrome браузер (загрузить с https://www.google.com/chrome/)

### 2. Установка зависимостей

Откройте Command Prompt или PowerShell в папке проекта и выполните:

```bash
pip install -r requirements.txt
```

Это установит:
- **Selenium** - для управления браузером
- **WebDriver Manager** - автоматически скачает нужный Chrome драйвер
- **openpyxl** - для работы с Excel файлами
- **ezodf** - для работы с ODF таблицами
- **pandas** - для обработки данных
- И другие зависимости

### 3. Запуск парсера

```bash
python main.py
```

Или указать номер строки для продолжения:

```bash
python main.py 50
```

## Что происходит при запуске?

1. Парсер запускает Chrome браузер в фоновом режиме (headless mode)
2. Для каждого ID из таблицы:
   - Загружает страницу с данными о поверке
   - Ждет загрузки JavaScript контента
   - Извлекает данные из таблицы
   - Записывает результаты в Excel файл
3. После обработки все ID браузер закроется

## Решение проблем

### Ошибка "No module named 'selenium'"
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### Excel файл занят другим процессом
- Закройте файл `Бойко А.П. Нет в ИС метрология.ods` если он открыт
- Повторите запуск

### Браузер зависает
- Проверьте интернет соединение
- Убедитесь, что сайт https://fgis.gost.ru доступен
- Перезагрузите парсер

## Структура проекта

- `main.py` - главный скрипт с логикой обработки
- `parser.py` - парсер на Selenium для загрузки данных с сайта
- `ExcelWorker.py` - работа с Excel/ODF таблицами
- `Card.py` - типизация данных карточки
- `requirements.txt` - список всех зависимостей
